# BNC email strategy

`email.html` is a standalone, responsive email marketing strategy prototype. Open it
locally in a browser, or publish the repository with GitHub Pages and visit
`https://vijayjai-design.github.io/BNC-email/email.html` once Pages is enabled.

The client details and email platform were not supplied, so the page deliberately
does **not** collect email addresses, send a confirmation, or issue a discount.
The form demonstrates required-field validation and consent only; submitting it
clears the fields and explains that no subscription was created.

Before using this as a live campaign:

1. Replace the proposed BNC branding, offer, and customer groups with the client's
   approved details.
2. Connect the form to an email marketing provider that records explicit consent,
   sends a double opt-in confirmation, and delivers the welcome offer only after
   confirmation. Replace the demo submission handler and notice with the provider's
   supported integration. Do not promise an offer until it is available.
3. Supply the actual physical mailing address, support contact, privacy policy,
   social profiles, and “What's New” landing page. Replace the preview's placeholder
   text with working links, including the provider's forward and unsubscribe links.
4. Verify the provider's confirmation, offer delivery, and unsubscribe flows, and
   enable GitHub Pages for the publishing branch.
